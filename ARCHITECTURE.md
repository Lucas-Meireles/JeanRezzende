# Arquitetura V1

- `pages/public`: experiência pública.
- `pages/owner`: torre de comando.
- `pages/artist`: espaço do artista.
- `layouts`: contextos privados.
- `components/motion`: linguagem de movimento.
- `store`: estado persistido.
- `styles`: tokens, responsividade e motion-safe.

Princípios: separar contextos, evitar duplicação, manter conteúdo editável pelo Owner e respeitar reduced-motion.
