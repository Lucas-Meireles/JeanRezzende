# Jean Rezende & Rodrigo • 

## Instalação

```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

Storybook:
```bash
npm run storybook
```

## Rotas

`/` público · `/gestao` Owner · `/gestao/historia` CMS da história · `/gestao/usuarios` equipe · `/gestao/suporte` chamados · `/artista` área do artista · `/artista/suporte` suporte · `/privacidade` · `/direitos`

## Stack

React, Vite, React Router, Zustand, GSAP, Framer Motion, Lucide, Sass, Tailwind CSS v4 e Storybook.

## Conteúdo visual

As 10 cenas geradas anteriormente foram individualizadas em `public/images/`. A composição original não é usada como mural na Home.

## Próxima camada

A versão atual é uma apresentação frontend independente. Integrações de backend, banco, autenticação e automações podem ser adicionadas em uma etapa posterior.
